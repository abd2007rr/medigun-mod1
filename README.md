# Medi Gun (Fabric 1.20.1)

Build:   gradle wrapper --gradle-version 8.8   (once, needs JDK 17)  then  ./gradlew build
Run:     ./gradlew runClient
Output:  build/libs/medigun-1.0.0.jar  (needs Fabric API + GeckoLib 4.4.x in mods/)

Controls: hold right-click = heal beam | sneak + right-click at 100% = ÜberCharge
Give item: /give @s medigun:medigun
